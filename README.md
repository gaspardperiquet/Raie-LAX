# Raie-lax

Site WordPress de réservation d'expériences touristiques durables à la mer : se déconnecter, se reposer et protéger les fonds marins.

Projet Digital 2 — Bachelier Écriture Multimédia, ISFSC.

## Concept

Raie-lax propose des activités au littoral qui respectent l'environnement (balades, ateliers, séjours déconnexion). Le site permet de découvrir les expériences et de les réserver en ligne.

## Outils

- WordPress (thème enfant de Twenty Twenty-Five)
- LocalWP (site en local)
- VS Code
- GitHub et GitHub Desktop
- Figma (maquettes)

## Conventions

### Branches
On ne travaille jamais directement sur `main`.

- `feature/nom` : nouvelle fonctionnalité
- `fix/nom` : correction de bug
- `docs/nom` : documentation
- `chore/nom` : mise en place, configuration

### Commits
Format : `type: description courte`

- `feat: ajoute le header`
- `fix: corrige le menu mobile`
- `docs: complète le README`
- `chore: arborescence du thème enfant`

### Fichiers
Noms en minuscules, mots séparés par des tirets, sans accents ni espaces.
